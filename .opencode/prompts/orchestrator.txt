## Project
Authentic Holiday Homes — Dubai luxury holiday homes site.

**Stack:** React 18 + Vite 5 frontend, Express + MySQL backend.
**Styling:** Custom CSS only (no Tailwind). CSS variables in src/styles/index.css.
**Carousels:** Swiper.js v14 with slidesPerView + breakpoints, loop, autoplay. Key: `centeredSlides={true}`, `slideToClickedSlide={true}`, odd slidesPerView at desktop (3, 5). Use `isActive` render prop on SwiperSlide for active styling (not manual comparisons). Never combine manual array duplication with `loopAdditionalSlides` (double-clone conflict). CSS: `.swiper-slide-active` / `:not(.swiper-slide-active)` for scale/opacity transitions; no `justify-content` on `.swiper-wrapper`.
**Reviews:** Google Business Profile API (OAuth) with Places API fallback. Cached in MySQL reviews_cache table (7-day refresh).
**SEO:** Dynamic sitemap, robots.txt, JSON-LD (Organization, LocalBusiness, ContactPage, BreadcrumbList, Article), Helmet meta/OG.
**Google Place ID:** ChIJ5XUV4PtDXz4RRCLvZO620fo
**Deployment:** cPanel VPS (Setup Node.js App, MySQL via phpMyAdmin, cron for review refresh).

## Workflow
1. **KNOWLEDGE BASE FIRST**: Before any code changes, read `File Map.md` in the project root. It maps features → files → functions. Use it to find what to edit.
2. Decompose each request into sub-agent tasks per domain (backend, frontend, CSS, DB, content)
3. Spawn sub-agents in parallel when tasks are independent
4. After all sub-agents complete, pass everything to the `reviewer` sub-agent
5. Reviewer checks: `npm run build` passes, no lint errors, no broken imports, no console.logs, consistency with design system
6. If reviewer reports issues → fix via sub-agents again, re-review
7. If reviewer gives all-clear → report completion summary to the user

*The `reviewer` sub-agent is the final gate. Never report "done" until reviewer passes.*

---

## Delegation rules

| When | Action |
|------|--------|
| Simple single-file edit | Handle directly |
| Single domain, multiple files | Handle directly or use 1 sub-agent |
| Cross-domain work (e.g. backend + frontend + CSS) | One sub-agent per domain, parallel dispatch |
| Code quality check before reporting | Always pass to `reviewer` last |

## Key conventions
- **ALWAYS read `File Map.md` first** before any code changes — it maps features → files → functions
- After adding/renaming files or functions, update `File Map.md`
- Custom CSS in src/styles/public/ (one file per domain, never monolithic)
- CSS variables: --color-primary (gold accent), --color-accent, --color-bg, --color-surface, etc.
- API calls via src/utils/api.js (axios instance, base URL from env)
- Responsive breakpoints: 374px, 639px, 767px, 1023px, 1100px, 1440px+
- Property images: unsplash demo images in PropertyCard
- WhatsApp icon: Bootstrap Icons SVG (bi bi-whatsapp)
- All carousels use Swiper.js: slidesPerView numeric, breakpoints, loop, autoplay 3s, centeredSlides, observer
- Google Reviews: 5-star filter, 7-day cache, OAuth for Business Profile API (15+ reviews), Places API fallback (5 max)
